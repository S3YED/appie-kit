# High-Ticket Coaching Funnel Architecture
## For £1k–£15k+ fitness coaching offers

### The Universal Flow
```
AD → VSL (7-40 min) → APPLICATION FORM (4-8 Qs) → TRIAGE CALL (15 min) → SALES CALL (45-60 min)
```

### Key Differences From Low-Ticket
| Element | Low-Ticket (£47–£997) | High-Ticket (£1k–£15k+) |
|---------|----------------------|------------------------|
| Goal | Collect payment on page | Book a discovery call |
| VSL Length | 2-5 min | 7-40+ min |
| Qualification | None | Application form (filters 60-80%) |
| Sales Mechanism | One-click checkout | Human sales call |
| CTA | "Buy Now" | "Apply Now" / "Book a Call" |

### Offer Stack
| Tier | Price | Funnel Type | Close Rate |
|------|-------|-------------|------------|
| Ignite | £997–£1,997 | VSL + Booking Call | 30-40% |
| Creed | £3,500–£5,000 | VSL + Application + Triage + Sales Call | 40-60% |
| Emperor | £10k–£15k | Application + Interview | 50-70% |

### Two-Call System
1. **Triage (15 min)** — Staff/VA: budget check, decision-maker, timeline
2. **Sales (45-60 min)** — Coach: discovery → solution → close

### Application Form (4-8 questions)
Order: Qualification questions FIRST (age, location, budget) → Contact info LAST

### Ad Creative Split (Hormozi model)
- 70%: "I've tried everything" educational angle
- 30%: "I need help" testimonial angle

Source: Alex Hormozi (Gym Launch, $100M+), Andy Frisella (75 Hard, $100M+), Ben Pakulski (Muscle Intelligence, $12k-$25k), Brian Gryn (Men's 40+ coach).
