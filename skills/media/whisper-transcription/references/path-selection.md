# Whisper Path Selection

## Local Whisper
Use the local CLI when offline processing, privacy, or low-friction transcription matters.

## OpenAI API
Use the API when you need hosted transcription, JSON outputs, or proxy-compatible access.

## Output Choices
- `txt` for plain transcripts
- `srt` for subtitles
- `json` for structured downstream processing

## Common Hints
- Provide language only when it improves accuracy.
- Use prompts for speaker names or domain vocabulary.
- Verify transcript length against audio length when quality matters.
