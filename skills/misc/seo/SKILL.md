# SEO Umbrella

## Overview
Use this umbrella for search-engine work that spans strategy, content, and technical implementation.

## Sections
- **Checklist / audits:** quick review paths and quality gates.
- **Keyword strategy:** research, intent clustering, page mapping.
- **Smart content:** briefs, outlines, optimization, and editorial fit.
- **Technical SEO:** indexing, crawlability, metadata, structured data, performance.
- **Backlinks:** outreach, authority building, and link opportunities.
- **Local / Dutch SEO:** region-specific phrasing and visitor-conversion tactics.

## Workflow
1. Start with intent and page purpose.
2. Decide whether the main need is content, technical, or off-page.
3. Apply the smallest set of changes that materially improve search performance.

## References
- `references/seo-families.md` for the SEO tactic families absorbed into this umbrella.

## Pitfalls
- Don’t split closely related SEO tactics into separate skills when one strategy umbrella fits.
- Don’t optimize content without checking technical constraints.
- Don’t treat checklist-style reviews as a separate domain; they are a format, not a category.
