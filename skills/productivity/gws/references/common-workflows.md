# Common GWS Workflows

## Email → Task
- Find the source message in Gmail.
- Extract the action item.
- Create or update the task in Google Tasks.
- Reply only if the user asked for follow-up.

## Meeting Prep
- Pull calendar attendees and event details.
- Gather linked Docs and Drive files.
- Draft a short agenda, risks, and decisions needed.

## Weekly Digest
- Combine calendar, unread email, and open tasks.
- Summarize what changed since the last run.
- Keep the output short and action-oriented.

## File Announce
- Share or verify the Drive link.
- Post the announcement in Chat with the correct audience.
- Include the smallest useful context, not a full document dump.

## Spreadsheet Workflows
- Backup, compare, report, or append rows in Sheets.
- Prefer schema-aware reads before writing formulas or ranges.

## Drive Workflows
- Organize folders, copy/share files, and manage permissions.
- Use shared drives for team content when appropriate.
- Check for large files or watch changes when storage or sync matters.

## Docs Workflows
- Create from template, save email to doc, or draft from a doc.
- Batch update when editing structured content.

## Calendar Workflows
- Block focus time, create recurring events, and reschedule meetings.
- Use free/busy before proposing new meetings.

## Safety
- Use Model Armor when user content needs filtering.
- Confirm before sending mail, changing shares, or deleting content.
