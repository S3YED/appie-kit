## Top AI Agent Gotchas (2026 state)

1. `tw-animate-css` not `tailwindcss-animate`
2. OKLCH not HSL for colors
3. Container parent needs measurable width
4. `@md:` (container) ≠ `md:` (viewport)
5. `components.json` must have `"rsc": true`
6. Static shadcn components are server-safe (no `'use client'` needed)
7. Tailwind v4 incompatible with Sass/Less preprocessors
8. No `forwardRef` — use `React.ComponentProps` + `data-slot`
9. Default style deprecated — use `new-york`
10. Toast deprecated — use `sonner`
